# Introducción a Algoritmos

Esta carpeta contiene un proyecto básico recuperado, que fue el proyecto final de la materia.

Este programa permite registrar usuarios de un gimnasio ofreciendo diferentes opciones de manejo del registro.

## Funcionalidades principales:

- Registrar un usuario, incluyendo su tipo de membresía o plan (Hay 2 tipos)
- Mostrar un listado con todos los miembros actuales
- Ingresar como miembro actual, para cambiar, renovar o cancelar su plan. También para cambiar la información ya registrada.
- Ingresar como desarrollador para cargar o guardar un archivo .txt con el listado de todos los miembros actuales
