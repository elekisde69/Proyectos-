# Estructura de Datos

Esta carpeta contiene los proyectos que realice o haya realizado en la materia.

## Habilidades aplicadas:

- Implementación y manejo de listas enlazadas simples y dobles
- Organización y manipulación de información mediante nodos
- Práctica con listas circulares (actualmente en proceso de aprendizaje)
- Aplicación de conceptos de abstracción y encapsulamiento**
- Uso de archivos para almacenar y recuperar información estructurada

Cada proyecto busca afianzar la comprensión de las estructuras lógicas que sustentan la programación eficiente.
